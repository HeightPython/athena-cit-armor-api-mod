# Athena — Custom Armor Texture API

[![Download Latest](https://img.shields.io/github/v/release/HeightPython/athena-cit-armor-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/HeightPython/athena-cit-armor-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Provides a clean API for mods to support custom armor textures via resource packs.

![Athena — Custom Armor Texture API Preview](https://cdn.modrinth.com/data/LN9hexaa/images/386582bc3bc22ee4d00a8a4d6cbfeceff22556f2_350.webp)

## Features

- Custom armor texture override via resource packs
- Compatible with OptiFine CIT armor format
- Works with Fabric, Forge, and NeoForge
- Layer-based rendering for complex armor designs
- Used by cosmetic and RPG mods for armor skins

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
